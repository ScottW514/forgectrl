GRBL serves standard Grbl senders on port 23. Factory cloud runs the machine against the Glowforge web service like stock firmware. The two are mutually exclusive; switching stops one controller and starts the other (machine must be idle) and persists across reboots.

Homing

Machine coordinates the head is at after a completed homing cycle. For Glowforge web-service homing that is the factory home corner (back left) with the lens at the hall reference — leave blank until a measurement says otherwise. To calibrate: home, jog to a known reference, and enter the measured offsets.

Cooling

Coolant-loop protection: each running job periodically verifies flow by running the loop heater and reading how far the downstream sensor climbs — past the fault rise means stagnant coolant. Blank fields use the built-in values (placeholders), measured on this machine's factory coolant; changes apply from the next job. These bands are per-machine: after a pump or coolant change, run Diagnostics → Cooling system to verify or re-measure them.

Machine identity

Credentials the machine signs in to the Glowforge web service with. Blank fields use the identity burned into the factory fuses — override only to stand in for another machine (64 hex digit password; the service hostname derives from the serial). Keep credentials secret; they cannot be changed once leaked. A blank password field keeps the current override.

Homing session

Overall budget for one web-service homing run (sign-in, camera uploads, hunt and corner moves). The controller aborts and alarms past this; 30–3600.

Print pause

Pressing the button during a cloud print pauses it: the head stops and retraces this many pulse ticks with the laser off; the next press resumes, moving forward with the laser off for the resume lead before it re-enables. The factory values are 2000 and 1950 (about 0.2 s at 10 kHz); 0–30000.

Controller

The motion controller speaks standard Grbl 1.1 (grblHAL) — point your sender at the connection above and use its device settings ($$) for the numbered GRBL parameters. The machine-level tunables below are read by the controller from the shared machine settings.

Laser arming

A job that fires the laser waits for the physical button (the light comes on) before its first fire; if nobody presses within the button wait the job is refused. Once armed, the window closes after the disarm grace with the laser off, and the next job asks again.

Motor rail

Off period observed before the 40 V motor rail is re-enabled on a controller takeover, so the stepper drivers always power up from a settled supply. 0 disables.

Lid lamp

Brightness of the lid lamp while the machine is idle; applied immediately, at every start, and after a mode switch. Cloud mode drives the lamp itself while it runs. 0 is dark.

Cooling system

These tools take the machine over: the motion controller is stopped, the loop heater and pump are driven directly, and the controller restarts when the tool finishes. The laser stays locked out throughout. Launch only when idle; all other controls lock until completion.

• Verify (~10 min): one flow check with the pump running and one with it stopped, judged against the configured fault rise — proves the threshold separates the two on this machine and coolant.
• Calibrate (~30 min): three trials per case; measures both bands and recommends a threshold at the midpoint. Run it after replacing the coolant (a different blend carries heat differently), swapping the pump, or a failed verify.

Log levels

Logger On this machine To remote server On disk

Every ForgeFIRM logger keeps its own directory under /data/log/forgefirm (size-capped, rotated). Levels are cumulative — warning keeps warnings and errors, debug keeps everything, off writes nothing; the two columns are independent. kernel is the glowforge driver and the rest of the kernel (its levels only filter what the kernel emits); system is everything else (SSH, WiFi, time sync). Changes apply at the next reboot.

Remote syslog server

Forwards each logger at its remote level as RFC 5424 syslog. Nothing is sent unless a server is set and at least one logger's remote level is on. An unreachable server never holds up the machine: undeliverable messages are dropped. Applied at the next reboot.

Log viewer

Export

A .tar.gz of every logger's files plus a system snapshot (firmware version, kernel ring buffer, uptime, memory, disk, processes, effective log levels, settings with secrets masked). The sanitized bundle is meant for attaching to a public issue report; placeholders keep the same number for the same value, so hosts can still be told apart. The sanitizer removes what it knows and what it can recognize — skim the bundle before posting it. Untick to keep everything for your own use.

Firmware slots

The eMMC carries two firmware slots (the factory A/B scheme); the SD card is the development boot medium. Set next boot changes only the saved boot selection — the machine keeps running until you reboot. Targets are probed first and unbootable ones are refused.
Switching to factory firmware: while factory firmware is online it may update itself and overwrite the other slot. Return to ForgeFIRM with sh /data/ffboot -e<slot> at the factory console.

ForgeFIRM update

Downloads are verified against the ForgeFIRM release signing key before anything can be written. Installing writes the selected slot; the running system is untouched until you set next boot and reboot.

Install or restore firmware

Every Install and Restore button below writes this slot and re-verifies it. The running system is never touched; the booted slot is not an option. After writing, use Set next boot above and reboot to switch.

Install a firmware image

Development images upload straight from the browser (dev-key signed — release.sh --dev); unsigned images need an extra confirmation.

Restore factory firmware

Restores an archived factory image (md5-verified against the archive manifest first). The Glowforge cloud is never required.

Wireless

Region rules set the WiFi radio's allowed channels and transmit power. Automatic follows the country the access point advertises (802.11d), falling back to the most-restrictive world rules; selecting a country pins it regardless of the AP (2.4 GHz channels 12–13 and the 5 GHz bands vary by region). Applied immediately and at every boot. WiFi power save stays off — on a mains-powered machine it only adds latency.

Fuse identity

Burned into the machine at the factory and unchangeable. Keep these secret — a leaked identity cannot be rotated, only abandoned.
